# Pack Cameroun (`cm`) — DRAFT

Toutes les valeurs de `pack.json` sont **indicatives** (« à valider »). Ce pack ne doit pas servir à produire une déclaration réelle avant relecture par un expert-comptable inscrit à l'ONECCA. Interface prévue en français et en anglais (`languages: ["fr", "en"]`).

## Sources à vérifier

| Composant | Valeur livrée | Source présumée à contrôler |
| --- | --- | --- |
| NIU | Lettre M/P + 12 chiffres + lettre | DGI Cameroun — attestation d'immatriculation |
| TVA | 19,25 % (17,5 % + CAC 10 %), taux zéro exportations | CGI art. 142 |
| IS | 30 % + CAC 10 % = 33 % (25 % + CAC pour CA ≤ 3 Mds non modélisé) ; minimum de perception 2,2 % du CA | CGI art. 17 et 21, LF 2022 |
| CNPS | PVID 4,2 % / 4,2 %, PF 7 %, AT groupe A 1,75 % ; plafond 750 000 | CNPS |
| IRPP salaires | Base = brut × 70 % − CNPS − 500 000/12 ; barème annuel 10 / 15 / 25 / 35 % ; CAC 10 % | CGI art. 30 et s., art. 69 |
| CFC / FNE | CFC 1 % salarié + 1,5 % employeur ; FNE 1 % employeur | CGI, textes CFC/FNE |
| RAV | Montants mensuels 0 à 13 000 selon le brut | Loi 87/021, CGI |
| Dépôt / calendrier | Télédéclaration DGI (teledeclaration-dgi.cm) ; TVA, acompte IS et retenues le 15 ; DSF 15/03 | DGI Cameroun |
| Facture certifiée | Non obligatoire | CGI, mentions obligatoires |
