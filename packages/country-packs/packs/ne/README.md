# Pack Niger (`ne`) — DRAFT

Toutes les valeurs de `pack.json` sont **indicatives** (« à valider »). Ce pack ne doit pas servir à produire une déclaration réelle avant relecture par un expert-comptable inscrit à l'ONECCA-Niger.

## Sources à vérifier

| Composant | Valeur livrée | Source présumée à contrôler |
| --- | --- | --- |
| NIF | Format générique (chiffres, suffixe lettre optionnel) | DGI Niger — attestation NIF |
| TVA | 19 % normal, 5 % réduit (produits de première nécessité) | CGI Niger, lois de finances |
| IS | 30 % ; IMF 1,5 % du CA, plancher 150 000 (taux et plancher incertains) | CGI Niger |
| CNSS | 5,25 % salarié / 15,4 % employeur (PF 8,4 %, pension 5,25 %, AT 1,75 %) ; plafond 500 000 | CNSS Niger |
| ITS | Abattement 17 % (incertain) ; barème mensuel 1 / 2 / 6 / 13 / 25 / 30 / 32 / 34 / 35 % ; sans charges de famille | CGI Niger, ITS |
| Dépôt / calendrier | Télédéclaration DGI (e-Taxes / SISIC, nom à confirmer) ; TVA et retenues le 15 ; états financiers 30/04 | DGI Niger |
| Facture certifiée | SECeF, déploiement progressif depuis 2023 ; connecteur `secef-ne` à implémenter | DGI Niger |
