# Pack Mali (`ml`) — DRAFT

Toutes les valeurs de `pack.json` sont **indicatives** (« à valider »). Ce pack ne doit pas servir à produire une déclaration réelle avant relecture par un expert-comptable inscrit à l'ONECCA-Mali.
