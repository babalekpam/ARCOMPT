# Pack Bénin (`bj`) — DRAFT

Toutes les valeurs de `pack.json` sont **indicatives** (« à valider »). Ce pack ne doit pas servir à produire une déclaration réelle avant relecture par un expert-comptable inscrit à l'OECCA-Bénin.

| Composant | Valeur livrée | Source présumée à contrôler |
| --- | --- | --- |
| IFU | 13 chiffres | DGI Bénin — attestation d'immatriculation |
| TVA | 18 % normal, exonérations | CGI 2022 (loi 2021-15) |
| IS | 30 % (25 % industries) ; impôt minimum 1 % du CA, plancher 250 000 | CGI 2022, lois de finances |
